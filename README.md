# ８人の預言者：静観の聖域 
8 PROPHET WEB PROYECT

> **「時間を止める静観。濁りのない真実を、ここに。」**

これは、独立した表現者・プログラマーとして構築した、私の作品群のための独自の静的ポータルサイトです。

## 👁️ コンセプト：静観 

現代の商業プラットフォームにおける「速さ」と「消費」のサイクルへの拒絶。
私の描く一線一線、色彩の一粒一粒を、時間を凍りつかせるような密度で体現するための場所です。

ここでは、スクロールによる断片化も、アルゴリズムによる操作も存在しません。ただ作品と向き合い、風の音や冷たさを感じるための「静謐な空間」を提供します。

## ⚔️ プロジェクト：８人の預言者 (Eight Prophets)

## 💻 技術仕様 (Technical Stack)

このサイトは、外部の毒（広告、トラッカー、過剰なスクリプト）を排除した純粋なコードで構成されています。

- **Engine:** Vanilla HTML5 / CSS3 / JavaScript (Client-side)
- **Architecture:** Static Site Generation / Recursive Image Loader
- **Hosting:** GitHub Pages
- **Philosophy:** Zero-Bloat, Utility-First Personalization
